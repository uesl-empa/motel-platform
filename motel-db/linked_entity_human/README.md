# Linked Entity Human

This folder contains a human-readable projection of the canonical linked-entity data.

- `../linked_entity/linked_entity.yaml`: canonical machine-oriented linked entities
- `linked_entity.yaml`: human-readable export with foreign keys expanded as `ID (Name)`

The export is generated by the helper notebook in the public code repository,
`motel-platform/motel-db/linked_entity_human/helper_linked_entity2human.ipynb`.
Run it with `MOTEL_DATA` pointing at this repository to regenerate the export
here after harmonising:

```bash
cd motel-platform
export MOTEL_DATA=../motel-data
jupyter nbconvert --to notebook --execute motel-db/linked_entity_human/helper_linked_entity2human.ipynb --output /tmp/helper-run.ipynb
```
